# AspectRatio

A World of Warcraft Forever addon that reminds hunters when they forget to turn on an aspect.

## Features

- Pulsing on-screen reminder with an optional warning sound when no aspect is active
- Pick a specific aspect (or any / none) per content type: open world, city/inn, dungeon, raid, battleground/arena
- Warns about the wrong aspect when a specific one is chosen
- Optional: combat-only reminders, hide while mounted
- Movable reminder icon

## Usage

Type `/aspect` to open the options, or find **AspectRatio** under Options → AddOns.

| Command | Description |
| --- | --- |
| `/aspect` | Open options |
| `/aspect unlock` / `lock` | Move the reminder |
| `/aspect combat` | Toggle combat-only reminders |
| `/aspect sound` | Toggle warning sound |
| `/aspect mount` | Toggle hiding while mounted |
| `/aspect test` | Toggle test display |
| `/aspect reset` | Reset position |
